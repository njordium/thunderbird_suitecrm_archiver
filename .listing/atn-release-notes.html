The interface now speaks thirteen languages US and UK English, Danish, Swedish, Norwegian Bokmål, Finnish, German, Spanish, Dutch, French, Italian, Polish and Brazilian Portuguese. Thunderbird's own language is followed automatically, and Preferences has a selector for anyone whose mail client and CRM do not share a language. This first pass covers the buttons, statuses, menu entries and notifications. The setup walkthrough and the permission explanations stay in English until a native speaker has reviewed them. A module your CRM refuses is turned off instead of complaining on every message
  • Filing a message could warn Could not search Prospects over and over, using SuiteCRM's internal name for the module the settings call Targets, which read like a complaint about a module you do not have. Every module name shown to you is now the one the settings use.
  • When a search fails, that module is checked once on its own. If the CRM refuses a plain read too, it stops being searched, is unticked in Preferences, and is marked there with the CRM's own reason and HTTP status. Re-scan modules re-tests it and clears the mark when access comes back, so a revoked role is something you can see and fix rather than a warning that never stops.
  • A module that answers a plain read is left alone, since that failure was about one request. A server error takes three failures in a row, every module failing at once is read as the CRM being unreachable, and the last remaining module is never turned off.
  • Filing sent mail automatically no longer ignores your module choice.
A reply goes where its conversation went
  • SuiteCRM stamps the case number into subjects it sends, and that used to be the only route, so the match was lost as soon as the subject changed. The add-on now also follows the mail thread, where SuiteCRM's own outbound case mail is already filed against the Case, and tells you which of the two found the match.
  • This is no longer limited to Cases. If an earlier message in the conversation was filed against an Account, a Contact or an Opportunity, a reply is offered there too.
  • The right-click menu and Alt+Shift+A now file where the window would. They went straight to the sender's history, so the same message could land in two different places depending on how you filed it.
Reading signatures Four fixes, each from a message that got it wrong. Med venlig hilsen and Med vennlig hilsen were not recognised as sign-offs, which is most Danish and Norwegian mail, so nothing after them was read at all. A company registration number in a legal footer was filed as a work phone number, which is worse than an empty field. A tel: link wrapped around a number hid it. And an attribution line that wraps before wrote: left two lines of somebody else's mail inside the signature. Also
  • Clearer wording throughout: the interface says file where it used to say archive, since Thunderbird's own Archive button moves mail to a local folder and means something else entirely. Archive now appears only where SuiteCRM is named in the same breath.
  • Find more modules is now Re-scan modules, because it re-tests refused modules as well as looking for new ones.
  • About has a Developer Support button that opens the issue tracker.
  • Three real races fixed: two windows saving a preference at once could lose one of the changes, pressing Change twice quickly could show one address with another's results, and switching between Lead and Contact while a signature parsed could fill the new form from the old one.
  • The privacy policy in the repository now lists every key the add-on keeps in your profile, and what a thread lookup sends.
